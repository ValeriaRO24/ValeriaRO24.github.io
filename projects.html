Understanding LLM Prompting for Responsible Student Use

    September 2025 – January 2026
  • Conducted an independent research study examining how prompt design impacts the performance, accuracy, and educational usefulness of large language models (LLMs) including ChatGPT, Gemini, and Claude.
  • Designed and implemented a systematic evaluation framework to analyze LLM responses across varying prompt conditions, including noisy vs. clean input, incomplete data, and differing educational levels, using algorithmic reasoning tasks (e.g. BFS, DFS, cycle detection).
  • Developed Python-based data processing and analysis pipelines to clean model outputs, compute readability metrics (Flesch–Kincaid, Gunning–Fog), and evaluate correctness, explanation quality, and prompt sensitivity.
  • Performed comparative analysis across models using quantitative metrics and structured checklists, identifying trade-offs in readability, conceptual depth, and error handling for educational applications.
  • Published reproducible research artifacts, including datasets, evaluation scripts, and analysis tools, in a public GitHub repository to support further research in AI-assisted education.

Computer Vision-Based Object Detection

Robotic Arm Programming and Control

    September 2023 – December 2023
  • The project involved programming a Panda robotic arm (by Franka Emika) using the Franka Control Interface to precisely manipulate common household objects. The arm was coded to execute a sequence of tasks in order, demonstrating fine motor control and automation.
  • The arm constructed a festive snowman from the ground up using Styrofoam balls and fabric accessories. It stacked the balls, drew facial features, wrapped a scarf, placed a top hat, and even sprinkled fake snow on top, showcasing multi-step object manipulation and tool use.
  • Inspired by the approaching winter season, this project was completed for the course Fundamentals of Robot Design (CSC376). It integrated concepts of robotic kinematics, programming, and task sequencing in a creative application.
